Debian Hardening Pro

A Debian hardening suite that enforces 16 CIS-aligned controls from one menu-driven runner: SSH lockdown, UFW firewall, Fail2Ban, auditd, USB storage blocking, secure umask, and core dump limits.

Built for repeatability. Each control is its own step with a repeat-safe guard, so the suite can run on a fresh build or re-run against an existing server without breaking what is already set. A run-all option applies the full baseline in one pass.

SSH Auto-Hardening

Automates SSH server hardening to the sshaudit.com Debian Bookworm standard: NIST-approved ciphers, MACs, and key exchange algorithms, regenerated host keys, and iptables rate limiting against brute force.

Host keys are regenerated at RSA 4096-bit and Ed25519. Weak moduli below 3071 bits are filtered out, and connection rate limiting is applied at the firewall so password spraying hits a wall before it reaches the daemon.

toolBashSSHLinux
source

SNMP Security Audit Tool

Audits SNMP posture across Linux systems and network devices: detects SNMPv1 and v2c community strings, checks listening interface binding, and inventories SNMPv3 user definitions.

Written after finding legacy community strings still alive on production systems. The remediation work that followed eliminated SNMPv1 and v2c across the environment and standardized on SNMPv3 with authentication and encryption.

toolBashSNMPNetworking

Check Point NAT IP Inventory

Extracts public IP addresses from Check Point NAT policy through the mgmt_cli API and produces a clean inventory for compliance reporting and asset documentation.

What was a manual reconciliation task is now a single script run. The output feeds compliance asset reporting directly, with no spreadsheet cleanup in between.

TLS Certificate Expiry Monitor

Monitors certificate expiry across a host inventory with configurable warning thresholds, so renewals happen before outages instead of after them.

Born from tracking certificates across Cisco voice and collaboration servers by hand. The monitor checks each host with OpenSSL and reports anything inside the warning window.
